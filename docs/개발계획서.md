# <이상한 빼빼로데이> – 개발 계획서

## 1. 개요
| 항목 | 내용 |
|---|---|
| 장르 | 비주얼 노벨 + 스테이지 끝 퍼즐 (방탈출 인터랙션) |
| 주인공 | 성해빈 (플레이어 = 남자친구) |
| 구성 | STAGE 1~4 + 퍼즐 3개 + "어? 오빠다!" 엔딩 |
| 플랫폼 | **웹 (HTML / CSS / JavaScript)** – 반응형 16:9 고정 캔버스 |
| 배포 | **Vercel** (링크 전달로 모바일/PC 즉시 플레이 가능) |
| 그래픽 제작 | 작가(수인님) 직접 제작 |

## 2. 화면 UI 규격 & 이미지 제작 가이드
- 기준 캔버스 해상도: **1920 × 1080 px (16:9 Full HD)**
  - 어떤 기기(모바일/PC)에서 접속하든 화면 중앙에 16:9 비율을 유지하며 상하/좌우 여백(레터박스)으로 깔끔하게 고정됩니다.

| 구분 | 권장 캔버스 크기 | 포맷 | 설명 |
|---|---|---|---|
| **배경 (Background)** | **1920 × 1080 px** | JPG/PNG | 비오는 길거리, 정자, 감자탕집, 지하철역, 가원중학교 등 전체 배경 |
| **전체화면 CG** | **1920 × 1080 px** | PNG | 여학생의 얼굴, 밝아지는 여학생 얼굴 등 씬 전체를 덮는 일러스트 |
| **소품 팝업** | **800 × 800 px** 내외<br>(가로 800~1000px) | **투명 PNG** | 하트 빼빼로 상자, 열린 상자, 감자탕, 편지봉투 등 중앙 오브젝트 |
| **퍼즐 전용 이미지** | **1000 × 750 px** ~ **1200 × 800 px** | PNG | 힌트와 글씨가 선명해야 하는 퍼즐용 이미지 (쪽지, 편지, 문제 상자) |
| **대사창 UI** | 코드 구현 (기본) | - | 상단 분리형 네임플레이트 + 반투명 아크릴 블러 대사 박스, 배경/캐릭터 빠른 페이드인·아웃 지원 |

## 3. 퍼즐 인터랙션 구현 방식
퍼즐 문제 이미지(배경/쪽지/내용)는 직접 그려서 제공되므로, 엔진에서는 그 위에 **사용자 인터랙션 입력 UI**만 띄웁니다.

| # | 문제 화면 이미지 (제공) | 입력 UI 연출 | 정답 판정 |
|---|---|---|---|
| 1 | 포스트잇 내용이 보이는 자물쇠 나무 상자 | 이미지 아래 5자리 회전 다이얼 (▲, ▼ 화살표로 알파벳 변경) | `TODAY` |
| 2 | 주황/분홍색 노선 십자가 태극무늬 쪽지 | 이미지 아래 깔끔한 텍스트 입력창 + [확인] 버튼 | `가락시장` / `가락시장역` (공백 자동제거) |
| 3 | w3w 편지 내용 ("자전거, 페달, 노력") | 이미지 아래 5글자 텍스트 입력창 + [확인] 버튼 | `가원중학교` (공백 자동제거) |

## 4. 시나리오 반영 내역 (확정)
1. **STAGE 1 정자 아재개그**: `독백 : 역시 난 유머 감각까지 완벽하다.` 추가 완료.
2. **STAGE 2 감자탕집**: 대사 원안 유지 ("아까 누가 혼자서 감자탕 시켜서 먹고 잔뜩 남기는 어린 남학생이 있으면 이걸 전해달라고 했어.")
3. **STAGE 3 호두할머니 티키타카**: `성해빈 : 오 저 수박 좋아해요. 다음에 깨주세요.` 로 유쾌하게 변경 완료.
4. **STAGE 3 가락시장역 일치**: 잠실역에서 가락시장역으로 이동한 직후 가락시장역에서 할머니와 만나는 동선 일치 완료.
5. **STAGE 4 날씨 연결**: 가원중학교 도착 직전 비가 다시 부슬부슬 내리기 시작해 교문 안으로 뛰어 들어가는 독백 반영 완료.
6. **STAGE 4 퍼즐 해설 타이밍**: 문제 3을 푼 뒤 STAGE 4 시작 시 해빈이가 `w3w`에 대해 이야기하며 이동하는 흐름 확정.
7. **엔딩 연출**: 여학생의 `"어? 오빠다!"`로 여운 있게 감동 마무리 확정.

## 5. 타이틀 및 스테이지 선택 화면 설계
- **타이틀 화면 (미니멀 감성)**:
  - 배경: [컨셉 1: 비 내리는 창가와 하트 상자 일러스트]
  - 텍스트/제목 폰트를 넣지 않고, 순수 일러스트 화면 위에 미니멀하고 세련된 버튼 2개만 배치:
    - `[ 게임 시작 ]` (START)
    - `[ 이어하기 / 스테이지 선택 ]` (STAGE SELECT)
- **스테이지 선택 화면 (모던 글래스모피즘)**:
  - 타이틀 배경 이미지를 실시간 CSS 블러 처리(`backdrop-filter: blur(14px)`)하여 분위기 있게 전환 (별도 이미지 제작 불필요).
  - 스테이지 카드 4개 배치:
    - **STAGE 1**: 정자와 자물쇠 상자 (기본 해금)
    - **STAGE 2**: 주은 감자탕 (문제 1 클리어 시 해금, 미해금 시 🔒 자물쇠 아이콘)
    - **STAGE 3**: 가락시장역과 호두할머니 (문제 2 클리어 시 해금)
    - **STAGE 4**: 비 내리는 가원중학교 (문제 3 클리어 시 해금)
  - 진행 상태는 브라우저 `localStorage`에 자동 저장되므로, 새로고침하거나 나중에 다시 들어와도 열려 있는 스테이지부터 바로 시작 가능.

## 6. 프로젝트 구조 및 개발 단계

### 디렉토리 구조
```
Ppeppero/
├── docs/                      # 기획서, 시나리오 원본, 그래픽 가이드
│   ├── 개발계획서.md
│   ├── 빼빼로데이게임 시나리오.txt
│   └── 이미지제작가이드.md
├── src/                       # 게임 소스코드
│   ├── index.html             # 메인 HTML (1920x1080 뷰포트 컨테이너)
│   ├── style.css              # 비주얼 노벨 UI 스타일링 (대사창, 팝업, 블러, 폰트)
│   ├── script.js              # 시나리오 스크립트 데이터 (STAGE 1~4)
│   ├── engine.js              # 대사 타이핑, 화면 전환, 팝업, 세이브 엔진
│   └── puzzles.js             # 다이얼 자물쇠 & 텍스트 인풋 인터랙션
├── assets/                    # 이미지 리소스 폴더
│   ├── bg/                    # 배경 이미지
│   ├── char/                  # 대화창 캐릭터 일러스트 (성해빈, 직원, 할머니)
│   ├── popup/                 # 팝업 이미지
│   ├── cg/                    # 이벤트 일러스트
│   ├── puzzle/                # 퍼즐 이미지
│   └── ui/                    # 타이틀 배경 등 UI
└── vercel.json                # Vercel 배포 설정
```

### 개발 마일스톤
1. **엔진 & 퍼즐 & 스테이지 선택 구현**: 임시 플레이스홀더로 STAGE 1~4 전체 대사, 퍼즐 3종, 스테이지 선택 기능 완성
2. **16:9 반응형 레이아웃 구축**: 모바일/PC 어디서나 왜곡 없는 고정 비율 세팅
3. **직접 그린 에셋 연동**: 수인님이 그리신 이미지 파일들을 `assets/`에 넣으면 바로 적용되도록 명명 규칙 정립
4. **Vercel 원클릭 배포**: 남자친구 전용 링크 생성 및 테스트
