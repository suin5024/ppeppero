# <이상한 빼빼로데이> – 그래픽 에셋 제작 가이드

본 문서는 게임에 필요한 모든 이미지 목록과 규격, 파일 이름, 작업 팁을 정리한 가이드입니다.  
아래 파일명 규칙대로 작업하여 저장해 두시면, 게임 코드에서 그대로 불러와 즉시 연결할 수 있습니다.

---

## 1. 기본 캔버스 & 해상도 가이드

- **기준 해상도**: **1920 × 1080 px (16:9 Full HD)**
- **에셋별 규격 & 크롭 원칙**:
  - **배경 / 전체화면 CG**: `1920 × 1080 px` (화면을 꽉 채우는 16:9 와이드, JPG 또는 PNG)
  - **소품 팝업 / 대화창 캐릭터**: 고정된 캔버스 크기를 맞출 필요 없이, **오브젝트/인물 외곽선에 맞춰 투명 여백을 크롭(Tight Crop)한 투명 PNG**로 저장하시면 됩니다. 게임 프로그래밍 단계에서 각 소품의 고유 비율을 유지하면서 최적의 위치와 크기로 자동 배치합니다.

---

## 2. 권장 저장 경로 (폴더 구조)

완성된 이미지는 프로젝트의 `assets/` 하위 폴더별로 나누어 저장하시면 됩니다.

```
assets/
├── bg/         # 배경 이미지 (1920x1080)
├── char/       # 대화창에 뜰 캐릭터 일러스트 (투명 PNG)
├── popup/      # 중앙 팝업 소품/쪽지 (투명 PNG)
├── cg/         # 전체화면 이벤트 일러스트 (1920x1080)
├── puzzle/     # 퍼즐 문제 전용 이미지
└── ui/         # 타이틀 화면 등 UI 관련
```

### ■ 대화창 캐릭터 일러스트 (화자 표시용)

대화창이 뜰 때 말하는 사람을 보여주는 캐릭터 이미지입니다. **두 가지 연출 방식** 중 원하시는 스타일대로 자유롭게 선택하실 수 있으며, 둘 다 **투명 배경 PNG**로 제작해 주시면 됩니다.

- **반신 스탠딩 (권장)**: 대사창 뒤쪽으로 캐릭터가 서 있는 전형적인 비주얼 노벨 방식으로, 가슴 위만 나오는 바스트업이 아니라 **머리부터 가슴, 배, 골반, 허벅지(하체 일부)까지 시원하게 보이는 3/4 반신 구도** (`Half-body down to mid-thighs`)
- **게임 적용 방식**: 고정 박스 크기 맞출 필요 없이, 인물 외곽선에 맞춰 여백을 크롭(Tight Crop)한 투명 PNG로 저장하시면 게임 코드에서 하단 대사창 뒤로 알맞게 서 있도록 자동 배치합니다.

| 체크 | 파일명 | 인물 | 권장 규격 | 캐릭터 외형 및 설명 |
|:---:|---|---|:---:|---|
| [ ] | `char/haebin_default.png` | **성해빈 (기본 모습)** | 여백 크롭 후<br>약 700×1100 px | 검은색 뿔테 안경, 나루토 그래픽 셔츠 위 지퍼 연 검정 패딩, 벨트 없는 편안한 바지. 덤덤하고 엉뚱한 기본 모습 |
| [ ] | `char/staff_default.png` | **감자탕집 직원** | 동일 규격 | 갈색 앞치마를 두른 친절하고 구수한 식당 이모님 |
| [ ] | `char/grandma_default.png` | **호두할머니** | 동일 규격 | 안경을 쓰고 호두를 든 비범하고 기묘한 분위기의 70대 할머니 |

> 💡 **안내**: 
> - 대화창 캐릭터는 인물당 기본 모습 1장씩만 사용하므로 표정 바리에이션을 따로 만드실 필요가 없습니다!
> - 엔딩에서 여학생의 대사는 화면 전체에 이벤트 CG(`cg/girl_face.png`, `cg/girl_smile.png`)가 꽉 채워져 연출되므로, 대화창 캐릭터 스프라이트 없이 텍스트만 깔끔하게 오버레이됩니다.
> - 독백(`독백 : ...`)이 나올 때는 캐릭터 모습이 숨겨지거나 대화창만 표시되어 자연스럽게 구분됩니다.

## 4. 에셋 개수 요약

- **배경 (bg)**: 7장
- **대화창 캐릭터 (char)**: 3명 (해빈, 직원, 할머니 각 1장씩)
- **팝업/소품 (popup)**: 6개 (하트 상자 닫힘/열림, 감자탕, 접힌 쪽지, 편지봉투, 서있는 여학생)
- **퍼즐 전용 (puzzle)**: 3장 (1번 자물쇠 상자, 2번 지하철 쪽지, 3번 편지)
- **전체화면 CG (cg)**: 2장 (여학생 얼굴 클로즈업, 밝아지는 표정)
- **UI (ui)**: 1장 (타이틀 배경)
- **총합**: **22장** (표정 중복을 없애고 엔딩 일러스트 중복 캐릭터를 제외하여 작업량이 훨씬 줄었습니다!)

## 5. 작업 시 알아두면 좋은 꿀팁

1. **배경 재사용**: 
   - 정자 배경(`pavilion.jpg`), 감자탕집 배경(`restaurant.jpg`), 지하철역 배경(`subway_inside.jpg`)은 시나리오 상 여러 번 다시 쓰이므로 한 번만 그리시면 됩니다.
2. **소품 투명 배경 (Alpha)**:
   - 팝업 사진(감자탕, 상자, 쪽지 등)은 뒤쪽 배경이 보여야 공간감이 살아납니다. 반드시 배경이 투명한 PNG로 저장해 주세요.
3. **글씨 가독성**:
   - 쪽지나 편지의 글씨는 스마트폰 작은 화면에서도 읽을 수 있게 살짝 큼직하고 두껍게 써주시는 것이 좋습니다.
4. **그림 완성 순서 팁**:
   - 처음부터 완벽하게 다 그리고 시작하지 않으셔도 괜찮습니다! 
   - 러프 스케치나 낙서 상태로 먼저 저장해서 엔진에 넣어 플레이해보고, 마음에 들 때 하나씩 완성본으로 덮어씌우면 훨씬 재밌고 편하게 작업하실 수 있습니다.
